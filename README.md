# Python 콘솔 퀴즈 게임

## 프로젝트 개요

입학 연수 미션을 위한 Python 콘솔 퀴즈 게임입니다. 사용자는 콘솔 메뉴에서 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록, 최고 점수 확인, 종료 기능을 사용할 수 있습니다.

구조는 `core`와 `cli`를 분리했습니다. 사용자 입출력은 `cli`가 담당하고, 퀴즈 모델과 게임 규칙, 저장소 경계는 `core`가 담당합니다.

## 퀴즈 주제와 선정 이유

초기 퀴즈 주제는 Python, Git, JSON 기초입니다. 이번 미션을 진행하면서 직접 다루는 개념을 복습할 수 있도록, 기본 문법과 저장 형식, Git 명령어를 중심으로 5개의 기본 퀴즈를 구성했습니다.

기본 퀴즈 예시는 다음과 같습니다.

- Python에서 리스트의 길이를 구하는 함수
- Git에서 변경사항을 기록으로 남기는 명령
- JSON 객체 표현 기호
- Python 조건문의 `elif` 키워드
- GitHub 원격 저장소 변경사항을 가져오는 명령

## 실행 방법

Python 3.10 이상에서 실행합니다. 외부 라이브러리는 사용하지 않고 표준 라이브러리만 사용하므로 별도 설치 과정은 없습니다.

1. Python 버전을 확인합니다.

```bash
python3 --version
```

`Python 3.10.x` 이상이면 실행할 수 있습니다. 환경에 따라 `python3` 대신 `python` 명령을 사용해야 할 수도 있습니다.

2. 프로젝트 루트 디렉터리로 이동합니다.

```bash
cd Codyssey_E1_2
```

현재 위치에 `main.py`, `core/`, `cli/`가 보이면 올바른 위치입니다.

3. 프로그램을 실행합니다.

```bash
python3 main.py
```

정상 실행되면 저장 파일 상태 안내가 먼저 출력되고, 이어서 다음 메뉴가 표시됩니다.

```text
나만의 퀴즈 게임
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
선택:
```

4. 메뉴 번호를 입력해 기능을 실행합니다.

- `1`: 저장된 퀴즈를 풀고 결과 점수와 최고 점수를 확인합니다.
- `2`: 문제, 선택지 4개, 정답 번호를 입력해 새 퀴즈를 추가합니다.
- `3`: 현재 등록된 퀴즈 목록을 확인합니다.
- `4`: 현재 최고 점수를 확인합니다.
- `5`: 현재 상태를 저장하고 프로그램을 종료합니다.

퀴즈 풀이와 퀴즈 추가에서 정답 번호는 `1`부터 `4` 사이의 숫자로 입력합니다. 빈 입력, 숫자가 아닌 값, 범위 밖 숫자를 입력하면 다시 입력하라는 안내가 출력됩니다.

5. 저장과 재실행을 확인합니다.

첫 실행 시 `state.json`이 없으면 기본 퀴즈 5개로 시작합니다. 퀴즈를 추가하거나 최고 점수가 갱신되면 프로젝트 루트의 `state.json`에 저장됩니다.

프로그램을 종료한 뒤 다시 실행하면 저장된 퀴즈 수와 최고 점수를 불러옵니다.

```bash
python3 main.py
```

저장 파일이 정상이라면 다음과 같은 안내가 출력됩니다.

```text
저장된 데이터를 불러왔습니다. (퀴즈 6개, 최고점수 100점)
```

`state.json`이 없으면 기본 퀴즈로 시작합니다. 파일이 손상되었거나 스키마가 맞지 않으면 기본 퀴즈로 복구해 실행하고, 이후 퀴즈 추가나 최고 점수 갱신처럼 저장이 발생하면 정상 형식의 `state.json`으로 다시 저장됩니다.

## 기능 목록

- 메뉴 출력 및 1-5번 숫자 입력 처리
- 퀴즈 풀기와 문제별 정답/오답 안내
- 전체 문제 수 기준 100점 환산 점수 계산
- 최고 점수 갱신 및 저장
- 새 퀴즈 추가
- 등록된 퀴즈 목록 확인
- `state.json` 저장 및 불러오기
- 저장 파일 없음, 손상 파일, 읽기 오류 안내
- 빈 입력, 숫자 변환 실패, 범위 밖 숫자 재입력 처리
- 입력 중 또는 최상위 실행 중 `KeyboardInterrupt`, `EOFError` 발생 시 현재 상태 저장 후 안전 종료

## 데이터 파일

데이터 파일은 프로젝트 루트의 `state.json`입니다. UTF-8 인코딩으로 저장하며, 프로그램 실행 중 생성되는 로컬 상태 파일이므로 `.gitignore`에 포함되어 있습니다.

저장 파일이 없으면 기본 퀴즈로 시작합니다. 저장 파일이 손상되었거나 스키마가 맞지 않으면 기본 퀴즈로 복구해 실행합니다.

스키마는 다음과 같습니다.

```json
{
  "quizzes": [
    {
      "question": "Python의 창시자는?",
      "choices": ["Guido", "Linus", "Bjarne", "James"],
      "answer": 1
    }
  ],
  "best_score": 0
}
```

- `quizzes`: 퀴즈 목록
- `question`: 문제 문자열
- `choices`: 선택지 4개
- `answer`: 1부터 4 사이의 정답 번호
- `best_score`: 최고 점수, 0부터 100 사이의 정수

현재 스키마는 과제 범위에 맞춘 최소 구조입니다. 필드가 늘어나는 운영 상황이라면 `schema_version` 같은 버전 필드를 추가해 이전 저장 파일과 새 저장 파일을 구분할 수 있습니다.

## 복구, 백업, 확장 한계

현재 프로그램은 파일이 없거나 손상된 경우 기본 퀴즈로 복구해 실행합니다. 자동 백업 파일은 만들지 않으므로 제출 전 중요한 `state.json`을 보존하려면 수동으로 복사해 둘 수 있습니다. 실제 서비스처럼 데이터를 반드시 보존해야 하는 상황이라면 저장 전에 `state.json.bak`을 만들거나 저장 파일 버전 관리를 추가하는 방식이 적합합니다.

모든 퀴즈는 실행 시 `list`로 메모리에 올라가고 저장 시 JSON 파일 전체를 다시 씁니다. 수십 개에서 1000개 정도의 학습용 데이터에는 단순하고 이해하기 쉬운 방식이지만, 데이터가 크게 늘어나면 검색 비용, 메모리 사용량, 파일 전체 쓰기 비용이 커질 수 있습니다. 그런 경우에는 데이터베이스, 페이지 단위 조회, 검색 인덱스 같은 구조로 확장하는 편이 좋습니다.
