- `README.md`의 `실행 방법` 섹션을 단계별 안내로 상세화했다.
- Python 버전 확인, 프로젝트 루트 이동, 실행 명령, 메뉴 화면 예시, 메뉴별 사용 방법을 추가했다.
- 첫 실행 시 `state.json`이 없을 때의 동작과 재실행 시 저장 데이터를 불러오는 흐름을 설명했다.
- 정답 번호 입력 범위와 잘못된 입력 처리 기준도 실행 안내에 포함했다.
