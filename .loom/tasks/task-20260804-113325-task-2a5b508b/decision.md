# 결정

- 새 문서는 기존 `doc/architecture.md`와 중복되지 않도록 “구조 명세”가 아니라 “과제 목표 질문에 답하는 근거집”으로 작성했다.
- 사용자의 초기 설계 생각은 별도 섹션으로 요약하고, Codex의 보충 판단은 책임 분리와 변경 이유 관점으로 덧붙였다.
- Git 기초는 Python 런타임 기능이 아니므로 코드 근거가 아니라 커밋 이력, `develop` 브랜치, `doc/submission-checklist.md` 기준으로 설명했다.
- README에는 새 문서 링크만 추가해 기존 실행/데이터 설명 흐름을 유지했다.
