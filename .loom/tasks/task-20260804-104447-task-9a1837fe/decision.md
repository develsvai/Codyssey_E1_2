# 결정

- 설계 기준 문서는 사용자가 요청한 경로에 맞춰 `doc/architecture.md`로 저장했다.
- 문서의 결론은 “현재 설계와 골격은 미션 구조 요구에 부합하지만, 최종 기능 조건은 아직 미충족”으로 정리했다.
- Loom proposal은 Active Memory로 확정하지 않고 `PROPOSED` 상태로만 남겼다. 사용자의 추가 수락 없이는 materialize하지 않는다.
- Loom docs index는 현재 workspace 설정상 `docs/`만 스캔한다. 사용자가 요청한 경로가 `doc/`이므로 문서 파일 확인과 proposal 기록을 이번 Task의 검증 기준으로 삼았다.
