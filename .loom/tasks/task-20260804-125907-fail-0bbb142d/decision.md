# 결정

- 보너스 기능 구현은 빠른 평가 보강 범위에서 제외했다. 현재 FAIL 항목은 대부분 제출 증빙과 운영 관점 문서화 부족이므로 필수 기능을 흔들지 않는 문서 보강을 우선했다.
- `signal` 모듈 기반 전역 핸들러 대신 `main.py`의 `try/except KeyboardInterrupt`를 선택했다. 현재 콘솔 앱 규모에서는 입력 루프 처리와 최상위 fallback 조합이 더 단순하고 설명하기 쉽다.
- 자동 백업 구현은 추가하지 않고 README와 설계 문서에 현재 한계와 확장 방안을 명시했다. 미션 범위에서는 손상 파일 복구와 실행 지속성이 핵심이다.
- GitHub push, merge, clone/pull, 스크린샷은 사용자 인증과 실제 화면 캡처가 필요하므로 문서 체크리스트로 분리했다.
