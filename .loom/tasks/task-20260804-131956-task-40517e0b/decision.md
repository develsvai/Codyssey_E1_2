# 결정

- 실제 캡처 이미지는 README보다 제출 증빙 문서인 `doc/submission-checklist.md`에 모아두는 것으로 정리했다.
- README에는 이미지 자체를 노출하지 않고 파일 구조에 `doc/image/` 경로만 표시해 메인 문서가 과하게 길어지지 않게 했다.
- 파일명에 공백과 한글이 포함된 이미지는 Markdown 링크 대상에 angle bracket을 사용해 링크가 깨질 가능성을 줄였다.
- 문서 보강 이후 새 커밋이 추가되므로 최종 제출 직전 최신 커밋까지 다시 push해야 한다는 주의 문구를 남겼다.
