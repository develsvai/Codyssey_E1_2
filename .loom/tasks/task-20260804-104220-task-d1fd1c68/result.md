# 결과

- 메뉴 1번 `퀴즈 풀기`가 실제로 동작하도록 구현했다.
- 저장된 퀴즈를 순서대로 출제하고, 각 문제의 선택지 4개를 출력한다.
- 정답 입력에서 빈 입력, 숫자 변환 실패, 범위 밖 숫자를 재입력 처리한다.
- 정답/오답 여부를 즉시 안내하고, 오답이면 정답 번호를 알려준다.
- 모든 문제 풀이 후 정답 수, 전체 문제 수, 100점 환산 점수를 출력한다.
- 최고 점수보다 높은 점수이면 `state.json`에 갱신 저장한다.
- 메뉴 입력과 정답 입력 모두 `KeyboardInterrupt`, `EOFError` 발생 시 저장 후 안전 종료하도록 공통화했다.

## 검증

- `python3 -m compileall .` 통과.
- `python3 main.py` 수동 실행으로 메뉴 1번 퀴즈 풀이 확인.
- 첫 문제 정답 입력에서 `abc`, `0` 입력 시 재입력 안내 확인.
- 기본 퀴즈 5개 정답 입력 후 `5문제 중 5문제 정답 (100점)` 결과 확인.
- 새 최고 점수 안내와 메뉴 4번 `최고 점수: 100점` 출력 확인.
- `loom validate --strict` 통과.
