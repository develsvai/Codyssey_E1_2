# Troubleshooting

- 전체 `git status`에는 이번 Task와 무관한 `AGENTS.md` EOF 빈 줄 변경이 계속 남아 있다. 이번 커밋에는 포함하지 않는다.
- `python3 -m compileall .`는 레포 루트에서 실행되어 `.git`과 `.loom` 디렉터리까지 순회해 출력이 길었지만 종료 코드는 0이었다.
- GitHub 원격 작업과 실제 스크린샷 촬영은 인증/화면 캡처가 필요하므로 자동 수행하지 않았다.
- 이전 검증 과정에서 ignored `state.json`에 테스트 퀴즈가 남아 있을 수 있다. 이 파일은 제출 커밋 대상이 아니다.
