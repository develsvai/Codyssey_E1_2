# 결정

- README는 제출자가 바로 확인할 수 있는 사용자-facing 문서로 유지하고, 자세한 제출 절차는 `doc/submission-checklist.md`로 분리했다.
- `doc/architecture.md`는 Active Memory `memory-20260804-104931-memory-47cda9f4`의 설계 기준 문서이므로 현재 구현 상태에 맞게 갱신했다.
- GitHub 인증이 필요한 `push`, 별도 디렉터리 `clone`/`pull`, 실제 스크린샷 촬영은 Task 범위상 직접 수행하지 않고 사용자 액션으로 문서화했다.
- `state.json`은 런타임 로컬 데이터 파일이므로 계속 `.gitignore`에 두고 커밋하지 않는다.
- Git 기초 명령어 7종 중 제출 전 확인이 필요한 `init`, `push`, `clone`, `pull`은 체크리스트에 별도 항목으로 남겼다.
